# Astro Band — прошивка

ESP32-S3-Zero (S3FH4R2) + GC9A01 + MAX30102 + MAX30205 + SCD41 + BMP390 + BMI270 + AD8232.

## Сборка (Arduino IDE)

Папка должна называться `astro_band` — так же, как `.ino`. Все `.h/.cpp` лежат рядом, IDE подхватит сама.

**Библиотеки (Library Manager):**

| Библиотека | Зачем |
|---|---|
| Adafruit GC9A01A (+ Adafruit GFX, Adafruit BusIO) | дисплей |
| Adafruit BMP3XX Library | BMP390 |
| SparkFun BMI270 Arduino Library | BMI270 (грузит в датчик конфиг от Bosch) |
| WebSockets — Markus Sattler (Links2004) | WSS-клиент |

MAX30102, MAX30205, SCD41 — свои драйверы, библиотеки не нужны.

**Tools:**

| Параметр | Значение |
|---|---|
| Board | ESP32S3 Dev Module |
| Flash Size | 4MB |
| PSRAM | **QSPI PSRAM** (OPI → бутлуп) |
| Partition Scheme | **Huge APP (3MB No OTA)** — с Wi-Fi + TLS прошивка может не влезть в 1.2 МБ дефолта |
| USB CDC On Boot | Enabled |
| USB Mode | Hardware CDC and JTAG |

## Перед прошивкой

1. `secrets.h` — Wi-Fi, хост/порт/путь WSS, `DEVICE_ID`.
2. `config.h` — пины, пороги тревог, профиль пользователя (`Cfg::HR_REST`, `SKIN_T_NORM`).

WSS: обычный TLS (Let's Encrypt на Traefik). Сертификат сервера не проверяется, без subprotocol
и без дополнительных заголовков (дефолтный `Origin: file://` библиотеки тоже убран).

## Архитектура

| Задача | Ядро | Приоритет | Что делает |
|---|---|---|---|
| `ecg` | 1 | 6 | AD8232 250 Гц, leads-off с антидребезгом, батарея. Единственный владелец АЦП |
| `sensors` | 1 | 4 | Единственный владелец I2C. PPG 50 Гц, IMU 25 Гц, остальное 1 Гц. Тревоги. Публикует снапшот 10 Гц |
| `ui` | 1 | 2 | 10 FPS, фреймбуфер 115 КБ, кадр целиком |
| `net` | 0 | 3 | Wi-Fi, NTP, WSS, очередь телеметрии |

Обмен: снапшоты `Vitals` / `AlertState` / `NetStatus` под критической секцией + lock-free кольца для ЭКГ и PPG-графика.

**Надёжность:**
- Task watchdog 10 с на `sensors` и `ui`.
- Устройство I2C после 10 ошибок подряд считается потерянным → recovery шины (9 тактов SCL + STOP) → переинициализация. Отсутствующие датчики переподключаются каждые 10 с (горячее подключение).
- MAX30102: запись регистров проверяется чтением обратно.
- Без USB-хоста Serial не блокирует (`setTxTimeoutMs(0)`).

## Сеть и протокол (Vigil v1)

- WSS `wss://WS_HOST/WS_PATH`, только **binary**, 1 кадр = 32 байта, 1 кадр/с. Сервер ничего не отвечает.
- Кадр формируется на смене секунды UTC → `ts` строго растёт, ровно один кадр в секунду.
  До синхронизации NTP кадры не формируются (сервер отбросил бы их как stale).
- Офлайн: кадры копятся в очереди (120 шт, 2 мин), после реконнекта уходят по порядку с флагом `HISTORY`.
- `dev_id` — `DEVICE_NUM_ID` в `secrets.h`, должен быть в crew table сервера.
- Кодирование — `protocol.cpp`, проверено байт-в-байт по тестовому вектору спецификации, CRC-16/CCITT-FALSE.

| Поле кадра | Источник | No data |
|---|---|---|
| hr ×10 | MAX30102, пульс | нет пальца / движение / < 3 ударов |
| spo2 ×10 | MAX30102, оценка (`PROTO_SEND_SPO2`) | как hr + < 8 ударов |
| rr | — | всегда 0xFFFF |
| skin_t ×100 | MAX30205, сглаженная | нет датчика |
| co2_ppm | SCD41 | до первого замера (5 с) |
| press ×10 | BMP390 | нет датчика |
| act_mg | BMI270: среднее за секунду от \|a\| − 1g | нет IMU |
| sqi | качество PPG 0–100 (90 = уверенный пульс) | 0 без пальца |
| flags | WORN (палец или кожа), ECG_CONTACT, MOTION_ARTIFACT, HISTORY | — |
| batt | % (делитель на ADC) | 0xFF, пока `BATT_ENABLED 0` |
| hrv | RMSSD по PPG, мс | < 20 чистых интервалов |
| amb_t ×100 | SCD41 (иначе BMP390) | нет датчиков |

## GUI

- **Норма** — дашборд: пульс, график ЭКГ (или PPG, если электроды сняты), SpO2*, кожа, CO₂, давление, статус сети. Кольцо зелёное.
- **Warn** — кольцо и значение метрики жёлтые.
- **Crit** — фокус-экран на проблемной метрике: значение, отклонение от нормы/базы, мигающее красное кольцо.
- Тревога поднимается, если держится 3 с, снимается после 5 с нормы. Невалидные данные (нет пальца, прогрев температуры, движение) тревог не дают.

## Ограничения (честно)

- **SpO2** — оценка по ratio-of-ratios с эмпирическими коэффициентами `SPO2_CAL_A/B`. Для реальных цифр нужна калибровка по эталонному пульсоксиметру. На экране помечено `*`.
- **HRV (RMSSD) по PPG** — при шуме завышается на 10–20 мс (предел опорной точки при 100 Гц).
- **SpO2** уходит на сервер, который проверяет жёсткие пороги. Без калибровки возможны ложные тревоги — `PROTO_SEND_SPO2 0` отключает поле.
- **Температура кожи** — 1–3 мин выхода на режим; до этого показывается прогноз `~`.
- **Скорость падения давления** считается по окну ~60 с — детект разгерметизации с задержкой до минуты.
- `PPG_LED_CURRENT 0x1F` подобран под палец. На запястье (отражение) поднимать до `0x3F..0x7F`.
